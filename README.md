# Third Eye Solar

Static GitHub Pages version of the Third Eye Tradezone website.

## Preview locally

Run any static file server from this directory, for example:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Publish with GitHub Pages

Push the `main` branch to GitHub, then open **Settings → Pages** in the repository. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The solar application form opens WhatsApp with the submitted details because GitHub Pages does not provide a form-processing backend.
